# CC Switch v4.0.36 · BlackBlade 定制版

本版本合并 farion1231/cc-switch 的主分支至 6da70837，包含上游 v4.0.1–v4.0.35 及该版本后的主分支更新。

- 更新供应商与托管账号集成、模型兼容性、技能仓库和会话管理。
- 修复 Codex 聚合模式、模型定价匹配及 OpenCode / Antigravity 用量统计。
- 保留团队供应商同步、工作室账号登录与凭据刷新、内置人民币定价、按模型覆盖接口协议和 Base URL。
- 适配上游拆分后的 Rust 模块及供应商数据库接口。

Windows x64 提供 MSI 安装包和 Portable ZIP。安装包、更新签名及 latest.json 由 GitHub Actions 构建并发布；应用内更新继续使用 blackbladestudio/cc-switch。
